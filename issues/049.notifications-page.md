Build the notifications page where users can view all their notifications, mark individual ones as read, and mark all as read.

## What to build

Create `NotificationsController` in `ChessHub.Web`:

- `Index` GET at `/notifications` — requires authentication
- Query all notifications for the current user, ordered by `CreatedAt` descending
- Pass to the view

Create `Index.cshtml` (notifications view):

- Page title: "Notifications"
- List of notifications, each showing:
  - Icon based on `NotificationType` (e.g., 🎮 for YourTurn, 🤝 for FriendRequest, ⚔️ for GameInvite, 🏁 for GameEnded, 🏆 for AchievementUnlocked)
  - Message text
  - Relative time ("2 hours ago")
  - Highlight unread notifications (different background color)
  - "Mark as read" button per unread item
- "Mark all as read" button at the top
- Empty state: "No notifications" when the list is empty

Add POST actions:

- `MarkAsRead(Guid id)` — marks a single notification as read, redirects back to `/notifications`
- `MarkAllAsRead()` — marks all as read, redirects back

When a notification links to a game or profile, make the message clickable so the user can navigate directly.

## Acceptance criteria

- [ ] `/notifications` page lists all notifications newest first
- [ ] Each notification shows type icon, message, and relative time
- [ ] Unread notifications are visually distinct
- [ ] "Mark as read" works per notification
- [ ] "Mark all as read" marks everything as read
- [ ] Bell badge updates after marking as read
- [ ] Empty state displayed when no notifications exist
