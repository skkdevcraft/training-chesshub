Build the `/friends` page showing the user's friends list with the ability to unfriend.

## What to build

Update `FriendsController.Index` GET at `/friends`:

- Requires authentication
- Query all friendships for the current user (where `UserId == currentUserId` in the `Friendship` table)
- Include the friend's User data (username, Elo, join date, profile link)
- Pass to the view

Create/update the `Index.cshtml` (friends view):

- **Pending Requests section** (from #041): incoming requests with Accept/Decline
- **Friends list**: each friend shows username (linked to profile), Elo rating, join date, and an "Unfriend" button
- **Add Friend section**: search-by-username form (from #040)
- Empty state: "No friends yet. Search for players to add!"

Add to `FriendsController`:

- `Unfriend(string friendId)` POST
  - Remove the `Friendship` row(s) between current user and friend
  - Both directions are removed (if using two-row model)
  - Redirect to `/friends`

Also update the profile page (#013): replace the "Friends list coming soon" placeholder with the actual friends list for that user (publicly visible).

## Acceptance criteria

- [ ] `/friends` page lists all friends with username, Elo, join date
- [ ] Each friend row has a profile link and "Unfriend" button
- [ ] Unfriending removes the friendship from both sides
- [ ] Pending requests section is integrated
- [ ] Add-friend search form is integrated
- [ ] Profile page shows the user's friends list (public)
- [ ] Empty states for both friends list and pending requests
