Create the EF Core `DbContext` in the `Data` project, register it, and verify the database is created via the first migration.

## What to build

In `ChessHub.Data`:

- Create an `AppDbContext` class inheriting from `DbContext`
- It can be empty for now (no `DbSet` properties) — just needs to exist so a migration can be generated
- Override `OnModelCreating` stub

In `ChessHub.Web`:

- Register `AppDbContext` in `Program.cs` with the Npgsql connection string

Run the EF Core tooling:

```bash
dotnet ef migrations add InitialCreate --project ChessHub.Data --startup-project ChessHub.Web
dotnet ef database update --project ChessHub.Data --startup-project ChessHub.Web
```

Verify the database and `__EFMigrationsHistory` table exist in PostgreSQL.

## Acceptance criteria

- [ ] `AppDbContext` class exists in `ChessHub.Data` with `DbContext` base
- [ ] `AppDbContext` is registered in `Program.cs` using `AddDbContext` with Npgsql
- [ ] `dotnet ef migrations add InitialCreate` completes without errors
- [ ] `dotnet ef database update` applies the migration
- [ ] PostgreSQL database exists and contains `__EFMigrationsHistory` table
