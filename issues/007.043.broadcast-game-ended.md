Push game-ending events and draw-offer events to both players in real time via SignalR.

## What to build

In the game-end logic (#027/#028 — checkmate, stalemate, draw, resignation):

- After setting the game status, broadcast `GameEnded` to the game group
- Payload: `result` (WhiteWon/BlackWon/Draw), `reason` (Checkmate/Stalemate/Resignation/etc.)

In the draw-offer logic:

- Broadcast `DrawOffered` when one player offers a draw
- Broadcast `DrawWithdrawn` when the offering player makes a move (implicit withdrawal) or explicitly withdraws
- Broadcast `DrawAccepted` when the opponent accepts
- Broadcast `DrawDeclined` when the opponent declines

On the client:

- Listen for `GameEnded` — lock the board, show result banner
- Listen for `DrawOffered` — show a notification "Opponent offers a draw" with Accept/Decline buttons
- Listen for `DrawAccepted`/`DrawDeclined`/`DrawWithdrawn` — update UI accordingly
- All events should update the status badge on the game page

## Acceptance criteria

- [ ] `GameEnded` event is broadcast on checkmate/stalemate/draw/resignation
- [ ] `DrawOffered` event is broadcast when a draw is offered
- [ ] `DrawAccepted`, `DrawDeclined`, `DrawWithdrawn` events are broadcast
- [ ] Opponent sees the result banner and locked board without page refresh
- [ ] Draw offer UI appears on the opponent's screen via SignalR
- [ ] Status badge updates for all clients
