Build the UI and controller to send a direct game invite to a friend or any user.

## What to build

Add to `LobbyController` or create an `InvitesController`:

- `SendInvite` GET — form with opponent selector (username input) and color selector (White/Black/Random)
- `SendInvite` POST:
  - Validation: cannot invite self, target must exist, no duplicate pending invite
  - Create `DirectInvite` with `Status = Pending`, `ExpiresAt = DateTime.UtcNow.AddHours(24)`
  - Create a `GameInvite` notification for the receiver

Add entry points for inviting:

- On the lobby page: "Invite Player" button that opens the invite form
- On a friend's profile or in the friends list: "Invite to Game" button
- On the `/friends` page: "Invite to Game" button next to each friend

Create the invite form as a partial view or dedicated page:

- Username input (pre-filled if coming from a profile/friend page)
- Color selector: White / Black / Random (radio buttons)
- Submit button
- Validation messages

## Acceptance criteria

- [ ] Authenticated, confirmed user can send a direct invite
- [ ] Cannot invite self
- [ ] Cannot send duplicate pending invite to the same person
- [ ] Target user gets a `GameInvite` notification
- [ ] `ExpiresAt` is set to 24 hours from creation
- [ ] "Invite Player" button visible on lobby page
- [ ] "Invite to Game" button visible on friend's profile and friends page
