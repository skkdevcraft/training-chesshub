Add custom 403, 404, and 500 error pages with user-friendly views, and add structured logging for key events.

## What to build

**Error pages:**

In `ChessHub.Web`:

- Create `Views/Shared/Error.cshtml` (generic error page)
- Create `Views/Shared/NotFound.cshtml` (404)
- Create `Views/Shared/Forbidden.cshtml` (403)

In `Program.cs`:

- `app.UseStatusCodePagesWithReExecute("/Home/Error/{0}")` — or use the built-in exception handler with re-execute
- `app.UseExceptionHandler("/Home/Error")` for unhandled exceptions (500)

Add a `HomeController.Error` action that accepts a status code and returns the appropriate view.

Each error page should:
- Display the error code and a friendly message
- Have navigation back to home
- Use `_Layout.cshtml`

**Logging:**

Add `ILogger<T>` injection throughout the application. Log the following events:

- User registration (Information)
- User login (Information)  
- Game creation (Information)
- Game completion (Information) — include result and both player IDs
- Unexpected exceptions (Error) — in the exception handler

Configure log level in `appsettings.json`:
- Default: Information
- Microsoft.AspNetCore: Warning

## Acceptance criteria

- [ ] Visiting a non-existent route returns a custom 404 page
- [ ] Unauthorized access to `/admin` returns a custom 403 page (when not admin)
- [ ] Unhandled exceptions return a custom 500 page
- [ ] Error pages include error code, friendly message, and navigation
- [ ] Registration and login events are logged
- [ ] Game creation and completion events are logged
- [ ] Exceptions are logged with full details (stack trace, request info)
- [ ] Log level is configurable via appsettings
