Build the player profile page showing username, join date, Elo rating, and statistics in a clean layout.

## What to build

Create `Index.cshtml` (profile view) with sections:

- **Header**: username (large), join date ("Member since …"), Elo rating
- **Statistics card**: a table or card grid showing Games Played, Wins, Losses, Draws, Win Rate (percentage)
- **Achievements placeholder**: a section labeled "Achievements" with a "Coming soon" message or empty state (will be filled in M11)
- **Friends placeholder**: "Friends list coming soon" (will be filled in M9)

Use the existing `_Layout.cshtml`. The view receives the `PlayerProfileViewModel`.

Add a link to the profile in the navbar when a user is logged in (their own profile) and in any future places that display usernames.

## Acceptance criteria

- [ ] Profile page displays username, join date, and Elo rating
- [ ] Statistics card shows Games Played, Wins, Losses, Draws, and Win Rate
- [ ] Win Rate is calculated correctly (Wins / GamesPlayed * 100, handle zero division)
- [ ] Achievements section shows placeholder
- [ ] Page uses `_Layout.cshtml` with proper page title ("{username} — ChessHub")
