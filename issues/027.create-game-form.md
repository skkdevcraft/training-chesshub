Build the form that lets an authenticated user create an open game with their desired color.

## What to build

Add to `LobbyController` in `ChessHub.Web`:

- `CreateGame` GET — requires authentication + confirmed email; returns a form with a color selector (White / Black / Random radio buttons)
- `CreateGame` POST — creates a `Game` entity:
  - Sets the creator as the appropriate player based on desired color (or randomly assigns White/Black for "Random")
  - Sets `Status = WaitingForOpponent`, `IsOpenInvite = true`, `ExpiresAt = DateTime.UtcNow.AddHours(72)`
  - `CurrentFEN` starts at the standard starting position

Create `CreateGame.cshtml` Razor view:

- Three radio buttons: White, Black, Random
- Submit button
- Validation summary

On success, redirect to the game page (`/games/{id}`).

## Acceptance criteria

- [ ] Only authenticated + email-confirmed users can access the create-game form
- [ ] Color selector shows White / Black / Random options
- [ ] POST creates a game with correct creator assignment and `WaitingForOpponent` status
- [ ] `ExpiresAt` is set to 72 hours from creation
- [ ] Successful creation redirects to `/games/{id}`
- [ ] For "Random" color, the creator is randomly assigned White or Black
