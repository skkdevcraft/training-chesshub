Create the `Friendship` entity representing a bidirectional friend relationship between two users.

## What to build

In `ChessHub.Domain`:

- Create `Friendship` entity:
  - `UserId` (string, FK to User — one side)
  - `FriendId` (string, FK to User — the other side)
  - `CreatedAt` (DateTime)

Since friendships are bidirectional (if A is friends with B, then B is friends with A), model this as a many-to-many self-referencing relationship on `User`. Use the EF Core many-to-many configuration with a join entity.

Alternatively, use two rows in the `Friendship` table (one for each direction) to simplify queries. The spec doesn't prescribe a specific approach.

In `ChessHub.Data`:

- Configure the many-to-many relationship:
  ```csharp
  modelBuilder.Entity<User>()
      .HasMany(u => u.Friends)
      .WithMany()
      .UsingEntity<Friendship>(
          j => j.HasOne<User>().WithMany().HasForeignKey(f => f.FriendId),
          j => j.HasOne<User>().WithMany().HasForeignKey(f => f.UserId)
      );
  ```
- Add a navigation property `ICollection<User> Friends` to the `User` entity

Run migration.
