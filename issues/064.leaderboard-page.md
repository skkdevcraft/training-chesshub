Build the public leaderboard page showing top players ranked by Elo, with pagination.

## What to build

Create `LeaderboardController` in `ChessHub.Web`:

- `Index` GET at `/leaderboard` — public, no auth required
- Query users ordered by `EloRating` descending, include `UserStatistics`
- Default: top 50
- Support pagination: `?page=2&pageSize=50`
- Pass to the view

Create `Index.cshtml` (leaderboard view):

- Page title: "Leaderboard"
- Table columns: Rank, Username (linked to profile), Elo, Games Played, Wins, Losses, Draws
- Rank column: sequential number starting from 1 for the first row, accounting for page offset
- Highlight the current logged-in user's row (if viewing while logged in)
- Pagination controls: Previous/Next buttons, page number display

Add navigation: link to `/leaderboard` in the navbar (publicly visible).

## Acceptance criteria

- [ ] `/leaderboard` is publicly accessible
- [ ] Players are ranked by Elo descending
- [ ] Table shows Rank, Username, Elo, Games Played, Wins, Losses, Draws
- [ ] Default page size is 50
- [ ] Pagination controls work for navigating pages
- [ ] Current user's row is highlighted
- [ ] Username links to profile page
- [ ] Leaderboard link in navbar
