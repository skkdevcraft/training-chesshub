Set up SignalR in the ASP.NET Core app and create the GameHub for per-game real-time communication.

## What to build

In `ChessHub.Web`:

- Add the SignalR NuGet package (`Microsoft.AspNetCore.SignalR` — included in ASP.NET Core)
- Create `Hubs/GameHub` class inheriting from `Hub` in `ChessHub.Web`
- Map the hub in `Program.cs`: `app.MapHub<GameHub>("/hubs/game")`
- Add the SignalR JavaScript client library to `wwwroot` (via npm/libman/CDN)

On the game page (`Game.cshtml`):

- Add JavaScript to connect to `/hubs/game` using the SignalR client
- After connection, call a hub method to join the game's group: the server creates a group per game (`game-{gameId}`)
- On disconnect, automatically leave the group (handled by SignalR)

The hub should have a `JoinGameGroup(string gameId)` method that adds the connection to `game-{gameId}`.

## Acceptance criteria

- [ ] SignalR is registered in `Program.cs`
- [ ] `GameHub` is mapped at `/hubs/game`
- [ ] SignalR JS client connects to the hub on the game page
- [ ] Client joins the group `game-{gameId}` on connection
- [ ] Server-side `JoinGameGroup` method adds the connection to the group
- [ ] No errors in browser console when loading the game page
