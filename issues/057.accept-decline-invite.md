When a user accepts a direct invite, create a game with the correct colors; when they decline, update the invite status.

## What to build

Add to `InvitesController` (or `GamesController`):

- `AcceptInvite(Guid inviteId)` POST
  - Verify the current user is the receiver
  - Verify the invite is still `Pending` and not expired
  - Create a new `Game`:
    - Assign players based on `DesiredColor`:
      - Sender chose White → sender = White, receiver = Black
      - Sender chose Black → sender = Black, receiver = White
      - Sender chose Random → randomly assign colors
    - `Status = InProgress`
    - `IsOpenInvite = false`
    - `CurrentFEN` = starting position
  - Update `DirectInvite.Status = Accepted`
  - Notify the sender: "Your invite was accepted. Game starting!"
  - Redirect to the game page `/games/{newGameId}`

- `DeclineInvite(Guid inviteId)` POST
  - Verify current user is the receiver
  - Verify the invite is `Pending`
  - Update `Status = Declined`
  - Notify the sender: "{username} declined your invite."
  - Redirect to `/notifications` or `/friends`

Show pending incoming invites on the notifications page or a dedicated section on `/friends` with Accept/Decline buttons.

## Acceptance criteria

- [ ] Accepting a direct invite creates a new game with correct player/color assignment
- [ ] Game status is immediately `InProgress`
- [ ] Invite status updates to `Accepted`
- [ ] Sender is notified of acceptance
- [ ] Declining updates invite to `Declined` and notifies sender
- [ ] Only the receiver can accept/decline
- [ ] Expired invites cannot be accepted
- [ ] Pending invites shown on notifications page with action buttons
