Seed the Administrator role and an initial admin user, then create the admin area controller with role-based authorization.

## What to build

**Role seeding:**

In `Program.cs` or a startup extension method, after the app builds:

- Create the `Administrator` role via `RoleManager<IdentityRole>` if it doesn't exist
- Create an admin user if one doesn't exist (configure email/password in `appsettings.Development.json` or user secrets)
- Assign the admin user to the Administrator role
- This should use `IServiceScopeFactory` to create a scope

**Admin area:**

Create `Areas/Admin` folder structure in `ChessHub.Web`:

- `Areas/Admin/Controllers/AdminController.cs`
- `Areas/Admin/Views/Admin/Index.cshtml`

In `AdminController`:

- `[Area("Admin")]` attribute
- `[Authorize(Roles = "Administrator")]`
- `Index` GET at `/admin` — returns a dashboard page listing available admin actions (view users, view active games — to be built in #055 and #056)

Configure area routing in `Program.cs`:

```csharp
app.MapControllerRoute(
    name: "areas",
    pattern: "{area:exists}/{controller=Home}/{action=Index}/{id?}");
```

## Acceptance criteria

- [ ] `Administrator` role is seeded on startup
- [ ] Admin user is created and assigned the role
- [ ] `/admin` is only accessible to users with Administrator role
- [ ] Non-admin users get 403 Forbidden
- [ ] Admin dashboard page shows links to Users and Active Games
- [ ] Area routing works: `/admin` → `AdminController.Index`
