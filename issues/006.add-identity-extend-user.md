Add ASP.NET Core Identity packages to the solution and create a custom `User` entity extending `IdentityUser` with application-specific fields.

## What to build

In `ChessHub.Domain`:

- Create a `User` class that extends `IdentityUser` (from `Microsoft.AspNetCore.Identity`)
- Add custom properties: `EloRating` (int, default 1200), `JoinDate` (DateTime), `SendEmailOnMove` (bool, default false), `CreatedAt` (DateTime), `UpdatedAt` (DateTime)

In `ChessHub.Web`:

- Add NuGet packages: `Microsoft.AspNetCore.Identity.EntityFrameworkCore`
- In `ChessHub.Data`, add a reference to `Microsoft.AspNetCore.Identity.EntityFrameworkCore`

The `Domain` project already has no EF Core references — confirm that `IdentityUser` is accessible there (it's in `Microsoft.AspNetCore.Identity`, which is not EF Core). If needed, place the `User` entity in `Data` instead, or add a thin Identity reference to `Domain`.

## Acceptance criteria

- [ ] `User` class exists inheriting from `IdentityUser` with all custom properties
- [ ] `EloRating` defaults to 1200
- [ ] `JoinDate` is set to `DateTime.UtcNow` on creation
- [ ] NuGet package `Microsoft.AspNetCore.Identity.EntityFrameworkCore` is added to `ChessHub.Web`
- [ ] Project compiles without errors
