Create a minimal home page to verify the entire stack works end-to-end: Docker services running, app starts, database is reachable, and a browser can load the page.

## What to build

- Create a `HomeController` with an `Index` action that returns a view
- Create the `Index.cshtml` Razor view — a simple welcome page with the app name "ChessHub"
- Set `Home/Index` as the default route (`{controller=Home}/{action=Index}`)
- In the `Index` action, optionally query the database (e.g., `dbContext.Database.CanConnect()`) to prove DB connectivity and display "Connected" or "Not connected" on the page
- Add a basic `_Layout.cshtml` with HTML5 boilerplate, a title, and `@RenderBody()`

Run the full stack: `docker compose up -d` → `dotnet ef database update` → `dotnet run`, then open the browser.

## Acceptance criteria

- [ ] `HomeController.Index` action exists
- [ ] `Index.cshtml` renders a welcome page
- [ ] `_Layout.cshtml` exists with `<title>ChessHub</title>` and `@RenderBody()`
- [ ] Navigating to `/` displays the home page
- [ ] Database connectivity is confirmed (no exceptions when loading the page)
- [ ] Full startup sequence works: Docker → migration → run → browser loads page
