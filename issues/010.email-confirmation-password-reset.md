Implement email confirmation during registration and a password-reset flow, using Mailpit for development email delivery.

## What to build

Configure `IEmailSender`:

- Create an `EmailSender` implementation in `ChessHub.Infrastructure` that connects to Mailpit's SMTP (localhost:1025, no auth)
- Register it in `Program.cs` via `AddTransient<IEmailSender, EmailSender>()`

Email confirmation flow:

- On registration in #008, generate an email confirmation token and send it
- Create `ConfirmEmail` GET action — validates token, marks email as confirmed, redirects to login with success message
- Display "Email not confirmed" notice to users who haven't confirmed when they log in

Password reset flow:

- `ForgotPassword` GET/POST — accepts email, generates reset token, sends reset link via email
- `ResetPassword` GET/POST — validates token, accepts new password + confirm, updates password, redirects to login
- "Forgot password?" link on login page points here

Verify emails appear in Mailpit's web UI at `http://localhost:8025`.

## Acceptance criteria

- [ ] `EmailSender` sends emails via Mailpit SMTP on port 1025
- [ ] Registration sends a confirmation email (visible in Mailpit)
- [ ] Clicking the confirmation link marks the email as confirmed
- [ ] "Forgot password" sends a reset email
- [ ] Reset password page validates the token and updates the password
- [ ] All emails are viewable in Mailpit web UI at `http://localhost:8025`
