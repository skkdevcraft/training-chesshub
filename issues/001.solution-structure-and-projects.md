Create the ASP.NET Core solution with a layered project structure following the dependency direction defined in the app spec.

## What to build

Create the `.sln` file and all five projects, then wire up project references so dependencies flow in one direction only: `Web` → `Application` → `Infrastructure` → `Data` → `Domain`.

- `ChessHub.Domain` — class library, no external dependencies (entities, enums, value objects)
- `ChessHub.Data` — class library, references `Domain`
- `ChessHub.Infrastructure` — class library, references `Data`
- `ChessHub.Application` — class library, references `Infrastructure`
- `ChessHub.Web` — ASP.NET Core MVC project (.NET 10), references `Application`

The solution must build successfully after all references are added.

## Acceptance criteria

- [ ] `ChessHub.sln` exists with all 5 projects
- [ ] Project references match the dependency direction: Web → Application → Infrastructure → Data → Domain
- [ ] `ChessHub.Domain` is a plain class library with no EF Core or ASP.NET references
- [ ] `ChessHub.Web` targets .NET 10
- [ ] `dotnet build` succeeds at the solution level

## Blocked by

None — can start immediately.
