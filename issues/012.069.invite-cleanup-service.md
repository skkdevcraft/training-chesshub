Create a `BackgroundService` that runs hourly to expire open games past 72 hours and direct invites past 24 hours, creating notifications for affected users.

## What to build

In `ChessHub.Web` (or `ChessHub.Infrastructure`):

- Create `InviteCleanupService` inheriting from `BackgroundService`
- Override `ExecuteAsync` with a loop that:
  - Runs every 1 hour (`await Task.Delay(TimeSpan.FromHours(1), stoppingToken)`)
  - On each run:
    1. Find open games where `Status == WaitingForOpponent` and `ExpiresAt <= DateTime.UtcNow`
       - Set `Status = Aborted`
       - Create a `System` notification for the creator: "Your open game has expired."
       - Broadcast `GameCancelled` to lobby hub clients
    2. Find direct invites where `Status == Pending` and `ExpiresAt <= DateTime.UtcNow`
       - Set `Status = Expired`
       - Create a `System` notification for the sender: "Your game invite to {receiver} has expired."
       - Create a `System` notification for the receiver: "A game invite from {sender} has expired."

Register the service in `Program.cs`:

```csharp
builder.Services.AddHostedService<InviteCleanupService>();
```

## Acceptance criteria

- [ ] `InviteCleanupService` runs as a hosted background service
- [ ] Expired open games transition to `Aborted` status
- [ ] Expired direct invites transition to `Expired` status
- [ ] Notifications are created for affected users
- [ ] `GameCancelled` is broadcast to lobby hub
- [ ] Service runs on a 1-hour interval
- [ ] Graceful shutdown via `CancellationToken`
