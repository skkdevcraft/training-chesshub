Build the admin page showing all active games with player info and status.

## What to build

In `Areas/Admin/Controllers/AdminController`:

- `Games` GET at `/admin/games` — query all games where `Status == InProgress` or `Status == WaitingForOpponent`, ordered by `LastMoveAt` or `CreatedAt` descending
- Include both players' usernames and Elo
- Pass to view

Create `Areas/Admin/Views/Admin/Games.cshtml`:

- Table columns: Game ID, White Player, Black Player, Status, Created, Last Move
- Read-only view — no actions to take on games
- Link each game ID to the game page (`/games/{id}`)
- If no active games, show "No active games."

Add a link from the admin dashboard to this page.

## Acceptance criteria

- [ ] `/admin/games` lists all active games
- [ ] Shows White Player, Black Player, Status, Created, Last Move
- [ ] Game IDs link to the game page
- [ ] Empty state when no active games
- [ ] Only accessible to Administrator role
