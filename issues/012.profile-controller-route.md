Create the profile controller and route that resolves users by username and returns their public profile data.

## What to build

Create `ProfileController` (or `PlayersController`) in `ChessHub.Web`:

- `Index(string username)` GET action — route: `/players/{username}`
- Query the user by `UserName` (the Identity property), include `UserStatistics` via EF Core `.Include()`
- If user not found, return 404
- Pass the user + stats to the view via a dedicated ViewModel

Create a `PlayerProfileViewModel`:

- `UserName`, `JoinDate`, `EloRating`
- `GamesPlayed`, `Wins`, `Losses`, `Draws`

This page is **public** — no `[Authorize]` attribute.

## Acceptance criteria

- [ ] `/players/{username}` route resolves to `ProfileController` (or `PlayersController`)
- [ ] Visiting `/players/existinguser` returns 200 with the profile ViewModel
- [ ] Visiting `/players/nonexistent` returns 404
- [ ] The page is publicly accessible (no auth required)
- [ ] `UserStatistics` is eagerly loaded with the user query
