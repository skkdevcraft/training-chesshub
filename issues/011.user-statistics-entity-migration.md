Create the `UserStatistics` entity to track games played, wins, losses, and draws, and seed empty stats on user creation.

## What to build

In `ChessHub.Domain`:

- Create `UserStatistics` entity with properties: `Id`, `UserId` (FK to `User`), `GamesPlayed` (int, default 0), `Wins` (int, default 0), `Losses` (int, default 0), `Draws` (int, default 0)
- Add a one-to-one relationship: `User` has one `UserStatistics`

In `ChessHub.Data`:

- Add `DbSet<UserStatistics>` to `AppDbContext`
- Configure the one-to-one relationship in `OnModelCreating`
- Run migration

When a user registers (in #008), automatically create a `UserStatistics` row with all zeros. This can be done in the `Register` POST action or via a database trigger / default. The simplest approach: after creating the user with `UserManager`, create and save a `UserStatistics` entity.

## Acceptance criteria

- [ ] `UserStatistics` entity exists with `GamesPlayed`, `Wins`, `Losses`, `Draws` (all default 0)
- [ ] One-to-one relationship between `User` and `UserStatistics` is configured
- [ ] Migration creates the `UserStatistics` table with FK to `AspNetUsers`
- [ ] Newly registered users automatically get a `UserStatistics` row with all zeros
- [ ] Existing test users can have stats manually seeded via database if needed
