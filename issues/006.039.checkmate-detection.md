Detect checkmate after each move, automatically end the game, and display the result.

## What to build

In the move handler, after each legal move:

- Call `IChessEngine.IsCheckmate(newFen)`
- If true:
  - Update `Game.Status` to `WhiteWon` or `BlackWon` (depending on who was checkmated)
  - Update `Game.UpdatedAt`
  - Save changes
  - Include `gameEnded: true, result: "WhiteWon"` (or `BlackWon`) in the response

On the client:

- When `gameEnded` is received, lock the board (make it non-interactive for both players)
- Display a prominent "Checkmate! {Winner} wins!" banner on the game page
- Update the game status badge

On initial game page load, if the game has ended, display the result banner and lock the board.

## Acceptance criteria

- [ ] Checkmate is detected after each move
- [ ] Game status auto-transitions to `WhiteWon` or `BlackWon`
- [ ] Board locks (no more moves accepted) after checkmate
- [ ] "Checkmate! {Winner} wins!" banner is displayed
- [ ] Game status badge updates to reflect the result
- [ ] Ended games show result on page load (no moves available)
