Build the admin page to list all users, disable accounts, and re-enable them.

## What to build

In `Areas/Admin/Controllers/AdminController`:

- `Users` GET at `/admin/users` — query all users with Elo, email, join date; pass to view
- `DisableUser(string userId)` POST — set `LockoutEnabled = true` and `LockoutEnd = DateTime.MaxValue` (or use Identity's built-in lockout)
- `EnableUser(string userId)` POST — set `LockoutEnabled = false` and clear `LockoutEnd`

Create `Areas/Admin/Views/Admin/Users.cshtml`:

- Table columns: Username, Email, Elo, Join Date, Status (Active/Disabled), Actions
- "Disable" button for active users (with confirmation)
- "Enable" button for disabled users
- User list should be paginated or at least ordered by username

Add links from the admin dashboard (`/admin`) to this page.

## Acceptance criteria

- [ ] `/admin/users` lists all registered users
- [ ] Disabling a user locks their account (prevents login)
- [ ] Enabling a user unlocks their account
- [ ] Status column shows Active or Disabled
- [ ] Confirmation before disabling
- [ ] Only accessible to Administrator role
