After a game ends and Elo/stats are updated, check if either player has unlocked any new achievements and create notifications.

## What to build

Create `AchievementService` in `ChessHub.Application`:

- `Task<List<Achievement>> CheckAndUnlockAsync(string userId)` — called after game completion
- For the given user, query all locked achievements (achievements not in `UserAchievement` for this user)
- Evaluate each achievement's condition:
  - **First Victory**: `UserStatistics.Wins >= 1`
  - **5 Games Played**: `UserStatistics.GamesPlayed >= 5`
  - **10 Games Played**: `UserStatistics.GamesPlayed >= 10`
  - **Reach 1400 Elo**: `User.EloRating >= 1400`
- For each newly met condition, create a `UserAchievement` row and add to the result list

Wire into `GameCompletionService` (#049):

- After updating Elo and stats, call `AchievementService.CheckAndUnlockAsync()` for both players
- For each newly unlocked achievement, create a notification: `Type = AchievementUnlocked`, `Message = "Achievement unlocked: {AchievementName}!"`

## Acceptance criteria

- [ ] Achievement conditions are evaluated after each game completion
- [ ] First Victory unlocks when Wins reaches 1
- [ ] 5/10 Games Played unlock at the right thresholds
- [ ] Reach 1400 Elo unlocks when crossing the threshold
- [ ] Newly unlocked achievements create `AchievementUnlocked` notifications
- [ ] Already-unlocked achievements are not re-unlocked
