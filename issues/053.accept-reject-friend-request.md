Implement the accept/reject flow for pending friend requests, creating a Friendship on acceptance and notifying the sender.

## What to build

Add to `FriendsController`:

- `AcceptRequest(Guid requestId)` POST
  - Verify the current user is the receiver of the request
  - Verify the request is `Pending`
  - Update `Status = Accepted`, set `ResolvedAt`
  - Create a `Friendship` between sender and receiver (insert two rows or one depending on modeling)
  - Create a notification for the sender: `Type = System` with message "{username} accepted your friend request"
  - Redirect to `/friends`

- `DeclineRequest(Guid requestId)` POST (or `RejectRequest`)
  - Verify the current user is the receiver
  - Verify the request is `Pending`
  - Update `Status = Rejected`, set `ResolvedAt`
  - Optionally notify the sender (or skip — the spec doesn't require rejection notifications)
  - Redirect to `/friends`

Add a "Pending Requests" section to the `/friends` page:

- List incoming requests (where current user is receiver and Status = Pending)
- Each shows sender username + time since request
- "Accept" and "Decline" buttons per request

## Acceptance criteria

- [ ] Accepting a request creates a Friendship between both users
- [ ] Accepting updates the request status to Accepted
- [ ] Declining updates the request status to Rejected
- [ ] Only the receiver can accept/decline
- [ ] Cannot accept/decline an already-resolved request
- [ ] Sender receives a notification when request is accepted
- [ ] Pending requests are listed on `/friends` with Accept/Decline buttons
