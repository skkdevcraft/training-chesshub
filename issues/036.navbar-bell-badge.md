Add a bell icon to the navigation bar that shows the count of unread notifications and links to the notifications page.

## What to build

Create a **View Component** in `ChessHub.Web`:

- `NotificationBellViewComponent`
- Invokes `INotificationService.GetUnreadCountAsync(currentUserId)` to get the count
- Returns a small partial view with:
  - A bell icon (🔔 or SVG)
  - A badge showing the unread count (only shown when count > 0)
  - Wraps everything in a link to `/notifications`

Add the View Component to `_Layout.cshtml` in the navbar:

```html
@await Component.InvokeAsync("NotificationBell")
```

The bell should only render for authenticated users.

To make the count update in real time (when new notifications arrive via SignalR), the bell's count can be updated via a SignalR event. For now, a page-load count is sufficient; real-time badge updates can be added when needed.

## Acceptance criteria

- [ ] `NotificationBellViewComponent` exists and is registered
- [ ] Bell icon is visible in the navbar for authenticated users
- [ ] Badge shows the correct unread count
- [ ] Badge is hidden when count is 0
- [ ] Bell links to `/notifications`
- [ ] Bell is not visible for unauthenticated users
