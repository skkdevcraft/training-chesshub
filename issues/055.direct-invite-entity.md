Create the `DirectInvite` entity for direct challenges between players, including status tracking and expiration.

## What to build

In `ChessHub.Domain`:

- Create `DirectInviteStatus` enum: `Pending`, `Accepted`, `Declined`, `Expired`
- Create `DirectInvite` entity:
  - `Id` (Guid)
  - `SenderId` (string, FK to User)
  - `ReceiverId` (string, FK to User)
  - `DesiredColor` (string — "White", "Black", "Random")
  - `Status` (DirectInviteStatus, default `Pending`)
  - `CreatedAt` (DateTime)
  - `ExpiresAt` (DateTime — `CreatedAt + 24 hours`)
  - Navigation properties: `Sender`, `Receiver`

In `ChessHub.Data`:

- Add `DbSet<DirectInvite>` to `AppDbContext`
- Configure relationships (two FKs to User)
- Add a constraint to prevent duplicate pending invites between the same two players (same direction)
- Run migration

## Acceptance criteria

- [ ] `DirectInviteStatus` enum with Pending, Accepted, Declined, Expired
- [ ] `DirectInvite` entity with all fields
- [ ] ExpiresAt defaults to CreatedAt + 24 hours
- [ ] Two FK relationships to User configured
- [ ] Migration creates `DirectInvites` table
- [ ] Duplicate pending invites prevented
