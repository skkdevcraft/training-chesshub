Detect when a player is in check after a move and display a visual indicator on the game page.

## What to build

In the move handler (#022/#025), after making a move and computing the new FEN:

- Call `IChessEngine.IsCheck(newFen)` to detect if the opponent is now in check
- Include `isCheck: true` in the move response JSON

On the client side (#021):

- When the response indicates check, display a "Check!" indicator on the game page (near the board or in the game header)
- Highlight the king that is in check (if cm-chessboard supports it)

On the game page load:

- When loading an existing game, also check if the current position has a check and display the indicator

## Acceptance criteria

- [ ] Server detects check after each move and includes it in the response
- [ ] "Check!" indicator is displayed on the game page
- [ ] Indicator is shown on initial page load if the position is in check
- [ ] Indicator is cleared when a move resolves the check

## Blocked by

- #025 — legal-move validation must be in place before check detection
