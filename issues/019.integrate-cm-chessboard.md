Add the cm-chessboard JavaScript library to the project and render a chess board on the game page from the game's FEN string.

## What to build

- Add `cm-chessboard` via npm/CDN or download the JS + CSS files into `wwwroot`
- Include the JS and CSS in `_Layout.cshtml` (or game-specific layout section)
- On the game page (`Game.cshtml`), replace the board placeholder div with a real cm-chessboard instance
- Initialize the board with the `CurrentFEN` from the game model (starting position for new games)
- Configure cm-chessboard as read-only for now (no move interaction yet — that comes in #021)
- Verify the board renders correctly: 8x8 grid with pieces in the starting position for a new game, or the correct position for an in-progress game

Board configuration should include: piece theme, board colors, responsive sizing, and orientation based on the viewing player (White player sees White at bottom, Black player sees Black at bottom).

## Acceptance criteria

- [ ] cm-chessboard JS and CSS are loaded on the game page
- [ ] Board renders as an 8x8 grid with chess pieces
- [ ] Board shows the correct position based on `CurrentFEN`
- [ ] Board orientation is correct: White at bottom for White player, Black at bottom for Black player
- [ ] Board is responsive (resizes with the page)
- [ ] New game shows the standard starting position
