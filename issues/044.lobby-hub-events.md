Create a second SignalR hub for the lobby so the open-games list updates in real time when games are created, joined, or cancelled.

## What to build

In `ChessHub.Web`:

- Create `Hubs/LobbyHub` inheriting from `Hub`
- Map it in `Program.cs`: `app.MapHub<LobbyHub>("/hubs/lobby")`
- No groups needed — all lobby clients receive all events (single room)

Wire up event broadcasting:

- When a game is created (#015): broadcast `GameCreated` to all lobby clients
- When a game is joined (#017): broadcast `GameJoined`
- When a game is cancelled (or expires): broadcast `GameCancelled` — this will be implemented properly in M12 with `InviteCleanupService`, but add a manual cancel action for now: the creator can cancel an open game

Event payloads should include: `gameId`, `creatorUsername`, `creatorElo`, `desiredColor`, `createdAt` (for `GameCreated`); `gameId` only for `GameJoined` and `GameCancelled`.

## Acceptance criteria

- [ ] `LobbyHub` is mapped at `/hubs/lobby`
- [ ] `GameCreated` is broadcast when a new open game is created
- [ ] `GameJoined` is broadcast when someone joins an open game
- [ ] `GameCancelled` is broadcast when a game is cancelled/expired
- [ ] Payload includes enough info for the lobby UI to add/remove/update game entries
