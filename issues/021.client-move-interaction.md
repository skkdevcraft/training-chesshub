Enable cm-chessboard for move input: let the player click a piece, see legal-move highlighting (provided by cm-chessboard), click a target square, and send the move to the server.

## What to build

On the game page:

- Configure cm-chessboard in **input mode** (not read-only) for the current player's turn
- Use cm-chessboard's built-in `moveInputCallback` or event to capture `from` and `to` squares
- Collect `from`, `to`, and `promotion` (if pawn reaches the last rank, show a promotion piece selector)
- Send the move data as a POST request to the server (endpoint built in #022)
- On response:
  - If success: update the board with the new FEN
  - If error: show error message (e.g., "Invalid move"), reset the board to the last valid position

Only allow moves when:

- The game status is `InProgress`
- It is the current user's turn (determined by whose turn it is based on the FEN — White's turn if FEN contains "w")

Disable the board for the player who is not on turn.

## Acceptance criteria

- [ ] Board is interactive for the player whose turn it is
- [ ] Clicking a piece highlights possible squares (cm-chessboard built-in)
- [ ] Clicking a target square triggers a POST with `from`, `to`, and optional `promotion`
- [ ] Promotion piece selector appears when a pawn reaches the last rank
- [ ] Board is disabled (non-interactive) for the player who is NOT on turn
- [ ] Invalid moves show an error message without corrupting board state
- [ ] Board updates visually after a successful move on the server
