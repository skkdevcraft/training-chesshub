Implement the Elo rating service that calculates new ratings for both players after a game ends.

## What to build

In `ChessHub.Application`:

- Create `EloService` and `IEloService` interface:
  - `(int newWhiteRating, int newBlackRating) CalculateElo(int whiteRating, int blackRating, GameResult result)`
  - Where `GameResult` is an enum: `WhiteWon`, `BlackWon`, `Draw`

The Elo formula:

```
ExpectedA = 1 / (1 + 10^((Rb - Ra) / 400))
ExpectedB = 1 / (1 + 10^((Ra - Rb) / 400))

NewRa = Ra + K * (ScoreA - ExpectedA)
NewRb = Rb + K * (ScoreB - ExpectedB)
```

Where:
- K = 32
- ScoreA = 1 for win, 0 for loss, 0.5 for draw
- ScoreB = 1 for win, 0 for loss, 0.5 for draw
- Ratings are integers (round the result)

Register `EloService` in DI as a scoped or singleton service.

Write a few unit tests (xUnit or similar) to verify the formula:
- Equal ratings, white wins → white gains ~16, black loses ~16
- 200-point difference, higher wins → smaller gain for higher-rated player
- Draw → both move toward each other slightly

## Acceptance criteria

- [ ] `EloService` implements the standard Elo formula with K=32
- [ ] Returns integer ratings (rounded)
- [ ] Unit tests verify: equal ratings win, rating difference win, draw
- [ ] `IEloService` interface exists and service is registered in DI
- [ ] Edge cases: ratings don't go below 0 or overflow
