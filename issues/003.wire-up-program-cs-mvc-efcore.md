Configure the ASP.NET Core application host: register services, set up the middleware pipeline, and make the app ready to serve requests.

## What to build

In `ChessHub.Web/Program.cs`:

- Add EF Core with the Npgsql provider, reading the connection string from configuration
- Register `DbContext` (placeholder or real when available)
- Add MVC controllers + views
- Add Razor Pages if needed (for Identity scaffolding later)
- Configure the HTTP middleware pipeline: exception handling, HTTPS redirection, static files, routing, authorization
- Use environment-specific configuration so Docker settings load in Development

No controllers or views yet — just the pipeline must be wired correctly so the app boots without errors.

## Acceptance criteria

- [ ] `Program.cs` registers EF Core with Npgsql using the connection string from config
- [ ] MVC services are registered (`builder.Services.AddControllersWithViews()`)
- [ ] Middleware pipeline includes: exception handler, HTTPS redirect, static files, routing, authorization
- [ ] `dotnet run` starts without unhandled exceptions (404 on `/` is acceptable at this stage)
- [ ] App listens on `https://localhost:5001` and `http://localhost:5000`
