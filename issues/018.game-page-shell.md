Build the game page that displays the current state of a game: who's playing, status, and a placeholder for the board.

## What to build

Create `GamesController` in `ChessHub.Web`:

- `Game(int id)` GET at `/games/{id}`
- Authorization: only the two players can view the game page (or an admin)
- Query the game with both players included, plus any moves (empty for now)
- Return 404 if game doesn't exist, 403 if not authorized

Create `Game.cshtml` Razor view:

- **Game header**: White player name + Elo vs Black player name + Elo, game status badge ("Waiting for Opponent", "In Progress", "White Won", etc.)
- **Board area**: a large placeholder div where the chess board will go (M5)
- **Move list area**: a placeholder "Moves will appear here" section (M5)
- **Game info**: created date, last move time, game status
- **Back to lobby** link

For `WaitingForOpponent` games, show a message "Waiting for an opponent to join…" instead of the board placeholder.

## Acceptance criteria

- [ ] `/games/{id}` loads the game page for authorized players
- [ ] Non-players receive 403 Forbidden
- [ ] White and Black player names + Elo are displayed
- [ ] Game status badge is shown and correct
- [ ] Board placeholder area is visible for `InProgress` games
- [ ] "Waiting for opponent" message shown for `WaitingForOpponent` games
- [ ] Move list placeholder is present
