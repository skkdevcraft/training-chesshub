Build the user registration flow: form, controller, and account creation.

## What to build

Create an `AccountController` in `ChessHub.Web`:

- `Register` GET action — returns the registration form
- `Register` POST action — accepts email, password, confirm password; creates user via `UserManager`; sets default `EloRating = 1200` and `JoinDate = DateTime.UtcNow`

Create the `Register.cshtml` Razor view:

- Email input
- Password input
- Confirm password input
- Validation summary for errors (password too short, duplicate email, password mismatch)
- Submit button

On successful registration:

- Redirect to a "check your email" page or home page with a success message
- The user is NOT automatically signed in (email confirmation required later)
- A confirmation email should be sent (placeholder for #010)

## Acceptance criteria

- [ ] `AccountController.Register` GET returns registration form
- [ ] `AccountController.Register` POST creates user in database
- [ ] Registration form has email, password, confirm password fields
- [ ] Validation errors are displayed (duplicate email, weak password, mismatch)
- [ ] New user has `EloRating = 1200` and `JoinDate` set
- [ ] Successful registration redirects with a success message
