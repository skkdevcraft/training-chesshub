Connect the lobby page to the LobbyHub so the open-games list updates automatically when games come and go.

## What to build

On the lobby page (`Lobby/Index.cshtml`):

- Add JavaScript to connect to `/hubs/lobby` via the SignalR client
- Listen for events:
  - `GameCreated` — append a new row to the games table
  - `GameJoined` — remove the game from the list (it's no longer open)
  - `GameCancelled` — remove the game from the list
- Update the "time since creation" display (relative time like "2 min ago") — this can use a periodic timer on each row or a separate update mechanism
- If the list was empty and a new game appears, hide the "No open games" message

The initial page load renders the server-side list (from #016). SignalR only handles incremental updates after load. No full page refresh needed.

## Acceptance criteria

- [ ] Lobby page connects to `LobbyHub` on load
- [ ] New games appear in the list without page refresh
- [ ] Joined games disappear from the list without page refresh
- [ ] Cancelled games disappear without page refresh
- [ ] "No open games" empty state appears/disappears correctly
- [ ] Browser console has no SignalR connection errors
