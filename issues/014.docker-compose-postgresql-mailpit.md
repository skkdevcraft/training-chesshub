Add a `docker-compose.yml` to spin up PostgreSQL and Mailpit for local development, and configure the connection string in `appsettings.json`.

## What to build

Create a `docker-compose.yml` at the solution root with two services:

- **PostgreSQL** — official image, exposed on default port 5432, with a named volume for persistence, environment variables for database name / user / password
- **Mailpit** — official image, exposed on its default SMTP (1025) and web UI (8025) ports

In `ChessHub.Web/appsettings.json` (and `appsettings.Development.json`), add a connection string that points to the Docker PostgreSQL instance.

Provide a `docker compose up -d` command the trainee can run to start both services.

## Acceptance criteria

- [ ] `docker-compose.yml` exists at solution root
- [ ] PostgreSQL service is defined with volume for data persistence
- [ ] Mailpit service is defined with SMTP (1025) and web UI (8025) ports
- [ ] Connection string in `appsettings.json` references the Docker PostgreSQL instance
- [ ] Running `docker compose up -d` starts both services successfully
- [ ] Mailpit web UI is accessible at `http://localhost:8025`
