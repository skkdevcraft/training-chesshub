When a game ends, calculate and apply Elo rating changes for both players, and update their `UserStatistics`.

## What to build

Create a `GameCompletionService` in `ChessHub.Application` (or add to `GameService`):

- Called whenever a game ends (checkmate, resignation, draw, etc.)
- Takes the `Game` entity and the result
- Calls `EloService.CalculateElo(whiteRating, blackRating, result)`
- Updates both players' `User.EloRating`
- Updates `UserStatistics` for both players:
  - `GamesPlayed += 1` for both
  - Winner: `Wins += 1`
  - Loser: `Losses += 1`
  - Draw: `Draws += 1` for both
- Uses a transaction with `RowVersion` concurrency check on the `Game` to prevent double-processing

Wire this into all game-end code paths from #027 and #028 (checkmate, stalemate, draw, resignation).

Display the Elo change on the game-end result banner:
- "White wins! Elo: {oldRating} → {newRating} (+{delta})"
- Same for loser: "Elo: {oldRating} → {newRating} ({delta})"

## Acceptance criteria

- [ ] Game completion triggers Elo calculation for both players
- [ ] Winner gains rating, loser loses rating (draws adjust both toward center)
- [ ] `UserStatistics` updated: GamesPlayed, Wins, Losses, Draws
- [ ] Transaction ensures atomic update of both ratings + statistics
- [ ] `RowVersion` prevents double-processing
- [ ] Elo change is displayed on the game-end banner
- [ ] Resignation also triggers Elo + stats update
