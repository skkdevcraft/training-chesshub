Handle all draw conditions (stalemate, threefold repetition, fifty-move rule, insufficient material), plus resignation and draw offers.

## What to build

**Stalemate detection:**

- After each move, call `IChessEngine.IsStalemate(newFen)`
- If true, set `Game.Status = Draw`, return `gameEnded: true, result: "Draw", reason: "Stalemate"`

**Other draw conditions:**

- Call `IChessEngine.IsDraw(newFen)` for repetition, 50-move, insufficient material
- If true, set `Game.Status = Draw`, include the specific reason in the response

**Resignation:**

- Add `Resign` POST action to `GamesController` at `/games/{id}/resign`
- Only the player whose turn it is can resign
- Set `Game.Status` to the opponent's win (`WhiteWon` if Black resigns, `BlackWon` if White resigns)
- Return `gameEnded: true, result: "...Won", reason: "Resignation"`

**Draw offer:**

- Add `OfferDraw` POST action at `/games/{id}/offer-draw`
- Only the player whose turn it is can offer a draw
- Store the draw offer state (can be in-memory or a flag on Game)
- Add `AcceptDraw` and `DeclineDraw` POST actions
- If accepted, set `Status = Draw`
- If the opponent makes a move, the draw offer is implicitly withdrawn

Update the client to display appropriate result banners for each condition.

## Acceptance criteria

- [ ] Stalemate auto-ends the game as Draw with reason "Stalemate"
- [ ] Threefold repetition, 50-move rule, and insufficient material auto-end as Draw with specific reason
- [ ] Resignation ends the game with the opponent winning
- [ ] Draw offer can be made only by the player on turn
- [ ] Draw offer is withdrawn when opponent makes a move
- [ ] Accepted draw ends the game
- [ ] All end-game conditions lock the board and display a result banner
- [ ] Result banner shows the specific reason (not just "Draw" but "Draw by stalemate")
