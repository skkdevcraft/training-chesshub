Show expiration timers on pending invites and open games so users know how long they have to respond.

## What to build

On the lobby page:

- For each open game, display "Expires in X hours" based on `ExpiresAt`
- Use a relative time or countdown format

On the notifications page:

- For `GameInvite` notifications, display "Expires in …" next to the Accept/Decline buttons
- Expired invites should not show Accept/Decline buttons, only "Expired"

On the `/friends` page (pending invites section):

- Same: show remaining time, disable actions when expired

On the game page for `WaitingForOpponent` games:

- Display a countdown: "Game expires in X hours Y minutes"
- The creator might want to cancel the open game — add a "Cancel Game" button (creator only) that sets `Status = Aborted` and broadcasts `GameCancelled` via LobbyHub

Client-side countdown can be implemented with JavaScript `setInterval` that updates the display every minute.

## Acceptance criteria

- [ ] Open games on lobby show "Expires in …" relative to `ExpiresAt`
- [ ] Pending invites show "Expires in …" on notifications and friends pages
- [ ] Expired items do not show action buttons
- [ ] "Cancel Game" button on own `WaitingForOpponent` games
- [ ] Countdown updates dynamically on the client side every minute

- #032 — LobbyHub must exist for GameCancelled broadcast
