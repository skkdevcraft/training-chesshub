Replace the achievements placeholder on the profile page with real earned achievements and a list of locked ones.

## What to build

Update the profile page (`Players/Index.cshtml` from #013):

- Replace the "Coming soon" achievements placeholder with:
  - **Unlocked achievements section**: list of earned achievements with name, description, icon/trophy, and unlock date
  - **Locked achievements section**: list of achievements not yet earned — show name, description, and a lock icon (greyed out)
  - If no achievements exist yet: "No achievements unlocked yet. Play games to earn them!"

The profile controller should include `UserAchievement` data in the ViewModel:

- List of unlocked achievements with unlock date
- List of locked achievements (all achievements minus unlocked ones)

Achievement display can be simple cards or badges with an icon (🎖️ for all, or specific icons per achievement).

## Acceptance criteria

- [ ] Profile page shows earned achievements with name, description, and unlock date
- [ ] Locked achievements are shown greyed out with lock icon
- [ ] Empty state when no achievements earned
- [ ] Achievements update on profile after they are unlocked (page reload shows new ones)
- [ ] Achievement section replaces the placeholder from #013

## Blocked by

- #051 — achievements must be unlockable
- #052 — profile page must exist (already does from #013)
