Build the UI and controller logic to send a friend request to another user by username.

## What to build

Create `FriendsController` in `ChessHub.Web`:

- `Index` GET at `/friends` — placeholder for now (will be used in #042); just requires auth
- `SendRequest` POST — accepts a `username` string
- Validation:
  - User must be authenticated with confirmed email
  - Cannot send request to self
  - Target user must exist (404 if not)
  - Cannot send duplicate pending request
  - Cannot send request to someone already a friend
- Create `FriendRequest` with `Status = Pending`
- Create a `FriendRequest` notification for the receiver via `INotificationService`

Add a "Send Friend Request" UI:

- Can be a search form on the `/friends` page, a button on the profile page (`/players/{username}`), or a small form in the navbar
- The simplest approach: on the profile page (#013), add a "Add Friend" button that POSTs to `/friends/send-request?username={username}`
- Display success/error messages

## Acceptance criteria

- [ ] Authenticated, confirmed user can send a friend request
- [ ] Cannot send request to self (error message)
- [ ] Cannot send duplicate pending request (error message)
- [ ] Cannot send request to existing friend (error message)
- [ ] Target user that doesn't exist returns 404
- [ ] `FriendRequest` is persisted with `Status = Pending`
- [ ] Receiver gets a `FriendRequest` notification
- [ ] "Add Friend" button is visible on other users' profiles
