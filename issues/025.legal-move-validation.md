Wire the chess engine into the move handler to validate every move server-side before persisting.

## What to build

Update the `MakeMove` POST handler (#022):

- Before creating a `Move` entity, call `IChessEngine.IsLegalMove(CurrentFEN, from, to, promotion)`
- If the move is not legal, return an error response: `{ success: false, error: "Illegal move" }`
- If legal, use `IChessEngine.MakeMove()` to compute the new FEN (replaces any manual FEN computation from #022)
- Use `IChessEngine.GetSAN()` to generate the SAN notation for the move

Update the client-side code in #021:

- On error response, display a user-friendly error message near the board
- Do NOT update the board position on error
- Allow the user to make a different move

## Acceptance criteria

- [ ] Every move is validated through `IChessEngine.IsLegalMove()` before persisting
- [ ] Illegal moves are rejected with a clear error message
- [ ] Legal moves use `IChessEngine.MakeMove()` to compute the new FEN
- [ ] SAN is generated via `IChessEngine.GetSAN()`
- [ ] Client displays error messages for illegal moves
- [ ] Board remains in correct state after a rejected move
