Display the move history for a game in a scrollable list alongside the board.

## What to build

On the game page (`Game.cshtml`):

- Replace the move list placeholder with a real move history display
- Query all moves for the current game, ordered by `MoveNumber`
- Render moves in a paired format: move number, white's move, black's move
- Display SAN notation for each move (e.g., `1. e4 e5`, `2. Nf3 Nc6`)
- The list should be scrollable (max-height with overflow-y) so the board remains visible
- Highlight the most recent move
- Auto-scroll to the bottom (most recent move) on page load

When a new move is made (via #021 + #022), update the move list dynamically without a full page reload — append the new move to the list and auto-scroll.

## Acceptance criteria

- [ ] Move history is displayed in paired format (move # | white move | black move)
- [ ] Moves use SAN notation
- [ ] List is scrollable and auto-scrolls to the latest move
- [ ] Most recent move is visually highlighted
- [ ] After a new move is submitted, the list updates without page reload
- [ ] Empty state: "No moves yet" when the game just started

## Blocked by

- #022 — moves must be persisted before they can be displayed
