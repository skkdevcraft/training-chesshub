Build login and logout flows with cookie authentication, and update the navbar to reflect auth state.

## What to build

Add to `AccountController`:

- `Login` GET — returns login form (email + password + "Remember me")
- `Login` POST — validates credentials via `SignInManager`, issues auth cookie on success, redirects to home
- `Logout` POST — signs out via `SignInManager`, clears cookie, redirects to home

Create `Login.cshtml` Razor view:

- Email input, password input, "Remember me" checkbox
- Link to "Forgot password" (placeholder until #010)
- Link to "Register" for new users
- Validation summary for invalid login

Update `_Layout.cshtml` navbar:

- When user is authenticated: show username (or email) and "Logout" link
- When not authenticated: show "Login" and "Register" links

## Acceptance criteria

- [ ] `Login` GET renders form with email, password, and remember-me
- [ ] `Login` POST signs in user with valid credentials, issues auth cookie
- [ ] `Login` POST shows error for invalid credentials
- [ ] `Logout` POST signs out and redirects to home
- [ ] Navbar shows Login/Register when logged out, username/Logout when logged in
- [ ] User is redirected to the page they originally requested after login (ReturnUrl)
