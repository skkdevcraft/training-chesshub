Create the `Achievement` and `UserAchievement` entities, seed the initial achievement definitions, and run the migration.

## What to build

In `ChessHub.Domain`:

- Create `Achievement` entity:
  - `Id` (Guid or int)
  - `Name` (string, e.g., "First Victory")
  - `Description` (string, e.g., "Win your first game")
- Create `UserAchievement` join entity:
  - `UserId` (string, FK to User)
  - `AchievementId` (FK to Achievement)
  - `UnlockedAt` (DateTime)
  - Composite primary key: `(UserId, AchievementId)`

Seed data in `OnModelCreating`:

| Name | Description |
|------|-------------|
| First Victory | Win your first game |
| 5 Games Played | Play 5 complete games |
| 10 Games Played | Play 10 complete games |
| Reach 1400 Elo | Achieve an Elo rating of 1400+ |

In `ChessHub.Data`:

- Add `DbSet<Achievement>` and `DbSet<UserAchievement>`
- Configure relationships and composite key
- Run migration

## Acceptance criteria

- [ ] `Achievement` entity with Name and Description
- [ ] `UserAchievement` join entity with UserId, AchievementId, UnlockedAt
- [ ] Seed data creates the 4 initial achievements
- [ ] Migration creates both tables
- [ ] Composite primary key on UserAchievement
