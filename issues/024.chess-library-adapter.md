Choose a .NET chess library, wrap it in an adapter, and register it for dependency injection.

## What to build

Research and select a .NET chess library (e.g., `ChessLib`, `Pgn.Net`, or similar) that supports:

- Parsing FEN
- Making moves (from/to, optional promotion)
- Validating legal moves
- Detecting check, checkmate, stalemate
- Detecting threefold repetition, fifty-move rule, insufficient material
- Generating FEN after a move

In `ChessHub.Application`:

- Create `IChessEngine` interface:
  - `bool IsLegalMove(string fen, string from, string to, string? promotion)`
  - `string MakeMove(string fen, string from, string to, string? promotion)` — returns new FEN
  - `bool IsCheck(string fen)`
  - `bool IsCheckmate(string fen)`
  - `bool IsStalemate(string fen)`
  - `bool IsDraw(string fen)` — covers repetition, 50-move, insufficient material
  - `string GetSAN(string fen, string from, string to, string? promotion)`

In `ChessHub.Infrastructure`:

- Implement `IChessEngine` using the chosen library — delegate to the library's API
- Register the implementation in `Program.cs` via DI: `builder.Services.AddScoped<IChessEngine, ChessEngineAdapter>()`

## Acceptance criteria

- [ ] A .NET chess library is added as a NuGet dependency
- [ ] `IChessEngine` interface exists in `Application` with all methods
- [ ] `ChessEngineAdapter` implements `IChessEngine` in `Infrastructure`
- [ ] Adapter is registered for dependency injection
- [ ] Basic smoke test: create a game in code, make `e2e4`, verify it returns a valid FEN
