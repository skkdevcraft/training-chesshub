Build the lobby page that displays all open games waiting for an opponent.

## What to build

Add to `LobbyController`:

- `Index` GET at `/lobby` — requires authentication + confirmed email
- Query all games where `Status == WaitingForOpponent` and `ExpiresAt > DateTime.UtcNow`, ordered by `CreatedAt` descending
- Include the creator user to display their username and Elo
- Pass the list to the view

Create `Index.cshtml` (lobby view):

- Page title: "Game Lobby"
- A table or card list of open games showing:
  - Creator username (linked to their profile)
  - Creator Elo rating
  - Desired color (White / Black / Random)
  - Time since creation ("5 min ago", "2 hours ago")
- "Join" button for each game
- "Create Game" button/link at the top
- Empty state: "No open games available. Create one!" when list is empty

## Acceptance criteria

- [ ] `/lobby` is accessible only to authenticated, email-confirmed users
- [ ] Lists all open games with creator username, Elo, desired color, and relative time
- [ ] Games past expiration are excluded
- [ ] "Join" button is displayed for each game (doesn't need to work yet)
- [ ] "Create Game" link opens the create-game form from #015
- [ ] Empty state message when no games exist
